# Trilium Reminder

Your Trilium to-do list, in front of you whenever you return to your PC: after sign-in, after every unlock and after every resume from standby.

![Trilium Reminder window with a short to-do list](/screenshot.png)

This is an unofficial project, not affiliated with the Trilium project.

- [Installation](./manual/install.md): Windows and Linux, download checks, updates, uninstall
- [Trilium setup](./manual/trilium-setup.md): the todo note, the token, HTTPS
- [Daily use](./manual/usage.md): mouse and keyboard, when the window opens, offline use
- [Linux](./manual/linux.md): wake service, KDE, i3, Wayland, tray, keyring
- [Troubleshooting](./manual/troubleshooting.md): every error message, restoring a revision, logs
- [Development](./manual/development.md): building, testing and releasing
